# CHANGELOG

Every change users can see — a command, an option, an output format or a message —
gets a line in `CHANGELOG.md` under `## [Unreleased]`, in `### Added`, `### Changed`
or `### Fixed`.

1. Ask whether a user of the shop CLI would notice this change. New behaviour,
   changed wording and fixed output all count.
2. If so, open `CHANGELOG.md` and add one bullet under `## [Unreleased]`, in the
   right section, describing the change in the user's terms.
3. Internal fixes that restore documented behaviour do not need one.
